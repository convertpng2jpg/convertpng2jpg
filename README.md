# ConvertPNG2JPG

Free, private image and PDF tools that run **entirely in your browser**. Your files never leave your device.

**Live site:** https://convertpng2jpg.com

## Features

- Runs in your browser, with no uploads to any server
- Free to use, with no sign-up and no watermarks
- Bulk conversion with ZIP download
- Transparent backgrounds are filled with white automatically
- Works on desktop, iPhone and Android
- English and Arabic versions available

## Tools

### Image converters
- [PNG to JPG](https://convertpng2jpg.com/): includes Under 50KB, 100KB and 200KB targets
- [JPG to PNG and AI Background Remover](https://convertpng2jpg.com/jpg-to-png.html)
- [WebP to JPG](https://convertpng2jpg.com/webp-to-jpg.html)
- [HEIC to JPG](https://convertpng2jpg.com/heic-to-jpg.html)
- [AVIF to JPG](https://convertpng2jpg.com/avif-to-jpg.html)
- [UAE Visa Photo Converter](https://convertpng2jpg.com/uae-visa-photo-converter.html): resize photos to GDRFA and ICP specs

### PDF tools
- [PDF to JPG](https://convertpng2jpg.com/pdf-to-jpg.html): up to 300 DPI, page range, ZIP download
- [PNG to PDF](https://convertpng2jpg.com/png-to-pdf.html)

- [Split PDF](https://convertpng2jpg.com/pdf-split.html)

## Privacy

All conversion happens locally using your browser. No files are uploaded, stored or shared.
